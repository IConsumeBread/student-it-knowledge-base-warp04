.NET CLI

Podstawowe polecenia .NET CLI
Polecenie Przykład Opis
dotnet --version dotnet --version Pokazuje używaną wersję SDK.
dotnet --list-sdks dotnet --list-sdks Wypisuje zainstalowane wersje SDK.
dotnet --list-runtimes dotnet --list-runtimes Wypisuje zainstalowane środowiska uruchomieniowe.
dotnet --info dotnet --info Pokazuje szczegóły instalacji .NET i systemu.
dotnet new list dotnet new list Wypisuje dostępne szablony projektów.
dotnet new console dotnet new console -n Hello Tworzy nową aplikację konsolową o podanej nazwie.
dotnet new sln dotnet new sln -n MojeRozwiazanie Tworzy plik rozwiązania grupujący projekty.
dotnet add package dotnet add package Newtonsoft.Json Dodaje pakiet NuGet do projektu.
dotnet restore dotnet restore Pobiera zależności projektu.
dotnet build dotnet build Kompiluje projekt.
dotnet run dotnet run Buduje i uruchamia aplikację.
dotnet test dotnet test Uruchamia testy jednostkowe projektu.
dotnet publish dotnet publish -c Release Przygotowuje aplikację do wdrożenia.
dotnet clean dotnet clean Usuwa wyniki kompilacji.
